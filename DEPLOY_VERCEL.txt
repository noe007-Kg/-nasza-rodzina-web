NASZA RODZINA v1.3.3 — WDROŻENIE VERCEL

1. Rozpakuj paczkę ZIP.
2. W repozytorium GitHub połączonym z Vercel podmień pliki na zawartość folderu Nasza_Rodzina_v1.3.3.
3. Zrób commit do main.
4. Vercel wykryje zmianę i wykona deployment.

Ustawienia Vercel:
- Framework Preset: Vite
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install

Firebase pozostaje tym samym projektem. Nie ma już Trybu DEMO ani przykładowych danych demonstracyjnych.
